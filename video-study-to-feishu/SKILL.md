# 视频学习笔记 → 飞书

把视频整理成帮助读者快速进入主题、选择回看位置的中文学习笔记。默认交付一份飞书云文档，遵从用户另行指定的语言、深度和目的地。适用于任何领域，按内容选择“论点、机制、操作步骤、故事线”等组织方式。

## 成果形态

在同一文档中按阅读深度组织，正文长度随内容调整：

| 阅读层 | 写什么 |
|---|---|
| 快速导读 | 一句话主旨、几个核心观点、带时间的章节、值得亲自看的片段 |
| 主题笔记 | 沿问题→解释或方法→关键过程→结果与启示组织；用重要图和少量必要背景帮助理解 |
| 关键画面索引 | 按原视频顺序完整保留非重复的重要课件、图表、演示步骤和有信息增量的动画；标时间和简短说明 |
| Q&A | 有问答时保留知识性问题、最终回答及改变含义的追问澄清；无问答则省略 |

正文已放过的图片，在索引中链接到该处，避免再次铺图。演示和纪录片用关键场景或步骤替代 PPT；访谈围绕讨论主题，只有提供额外信息的画面才配图。少量无法确认且影响理解的内容就地简短标注。

## 工作流程

### 1. 取得材料

确认目标视频、语言、已有课件和目标云文档。上下文足够时直接推进，常规整理不另设大纲审批。用户自己的笔记用于学习对照时，新建独立文档；收到更新指定文档的请求则就地维护。

字幕、音轨、课件和画面获取方式见 [获取材料与飞书交付](references/operations.md)，在对应操作前阅读。优先使用已有字幕；缺失或质量差时转写可访问的音视频。有字幕但拿不到画面时，交付明确标识的文字版，不宣称完整保留课件。只有部分材料时限制分析范围，不拿论文、网页摘要或其他人的笔记冒充视频内容。

### 2. 通览内容与画面，再决定取舍

先沿全时间轴建立内部材料清单：章节、字幕、课件变化、关键演示、问答、未来方向。清单只服务整理，不作为正文展示。

- 联合读取画面和字幕。无字幕、只配音乐的图解、图表注释、结尾蓝图和问答也可能是核心内容。
- 每个非重复的知识性页面先纳入清单，再决定放正文还是画面索引。不要只给已写好的字幕摘要配几张图。
- 同页动画按信息变化处理：只变化手势或光标可去重；新增箭头、流程步骤、条件、指标、结论应保留。最终状态覆盖了完整含义时可用完整图；中间状态表达执行顺序时保留关键阶段。
- 先找演讲者的问题与论证路线，再定章节。保留能回答“为什么这样设计、解释或操作”的内容。

### 3. 撰写导读和主题笔记

导读应让读者知道视频讲什么、核心贡献或观点是什么、各章在哪里、哪些地方值得自己看。章节按有意义的主题划分，时间用于导航，不机械按固定分钟数切段。

主题笔记用自然段连贯说明。专业背景仅补足理解当前内容所需的概念，适配读者已有知识；用户追问时再深入。讲者的研究方向、已实现能力、个人判断分别准确表达；对意图的推断用“可理解为”等自然措辞。

**正文表达规则：**

- 正文展示知识和论证。文件名、哈希、字幕条数、命令结果、回读过程、权限处理和覆盖检查放在工作记录中。
- 通篇不套用“讲者内容／解读／证据边界”三段标签，也不反复列举讲者没有证明的事项。
- 结论有适用条件时，直接写进句子，例如“在两个样区、8 周观测中……”；确实改变理解的缺口简短标明，例如“问题前半句听不清”。
- 性能或实验结果连同指标、负载和关键条件写，避免扩写成普遍保证。事实含义不清时保留缺口，不能为了简洁而写得更确定。
- 核对、纠错和来源追踪继续在内部进行。用户请求审计、事实核查或复现时，再按其要求单独展开。

### 4. 配图与 Q&A

关键画面必须能帮助理解论点、过程或结果。完整保留重要架构图、数据流、操作步骤、实验图、适用条件、总结蓝图和未来方向；不设固定截图配额。图注提供“时间＋这张图解释什么＋原视频定位”。保证关键区域可读，保留坐标、图例和必要注释。

Q&A 写“问题＋回答”，只补充改变结论的澄清或必要解释。穿插提问和末尾提问都检查；不要把先误解后纠正的答复合并成相反结论。保留讲者未回答的实质问题，听不清的部分简短标记，不反向编造问题。省略设备调试等行政问答；没有 Q&A 时不制造问答章节。

时间链接指向原视频位置；剪辑、音轨偏移或字幕清洗后的时间必须映射回原片。重复字幕可合并，原文和时间映射留在工作材料中，不默认把完整逐字稿塞进阅读正文。

### 5. 写入、回读、交付

用 lark-doc 完成云文档；将媒体插入对应内容处，长文分章写入同一文档。回读并检查正文顺序、时间链接、图片位置、关键画面清单和知识性问答的覆盖。发现缺漏在原文档修复。

最终回复给出云文档链接与简短内容说明。若关键材料或云文档发布受阻，说明实际缺口和下一步；不能用占位图、空问答或未发布草稿冒充已完成成果。

## 容易偏离的地方

| 现象 | 调整 |
|---|---|
| 读起来像 agent 的核查报告 | 改成知识导读；核查过程留在工作材料中 |
| 字幕主旨齐全，重要图仍缺失 | 回到全片画面清单，补齐无口述页面和动画信息 |
| 图很多，主线不清 | 正文突出论证；其余重要图按章节留在索引 |
| 每个领域都套数据库设计章节 | 按视频的研究问题、叙事或操作目标组织 |
| 摘要显得比原视频更完整确定 | 保留实质性未知、争议、适用范围和讲者的未回答问题 |

## 表达示例

“这段视频提出，珊瑚恢复需要从一次干预走向持续反馈。04:40 的完整流程新增季度复测，06:30 的样区结果帮助理解这一思路。结果来自两个条件不同的样区，不能直接当作所有海域的恢复效果。10:30 的协作蓝图展示未来如何把监测与研究平台连接起来。”

此例给出主旨、关键画面、必要条件和回看入口；正文不附字幕校正日志、截图统计或工具验收说明。
